# 🎣 Pesca Amadora — Verificação de Limites

Projeto desenvolvido em **C#** como atividade acadêmica da **ETEC Adolpho Berezin — Mongaguá/SP**.

## 📚 Sobre o projeto

O programa **Pesca Amadora** foi desenvolvido para praticar conceitos de programação em C#, como:

* Declaração de variáveis e constantes;
* Estruturas condicionais (`if/else`);
* Operadores lógicos;
* Métodos e funções;
* Conversão e validação de dados;
* Cálculos matemáticos;
* Formatação de valores monetários;
* Entrada e saída de dados pelo console.

O sistema solicita ao usuário o **peso do pescado** e o tipo de água onde ocorreu a pesca, podendo ser **águas continentais** ou **águas marinhas**.

A partir dessas informações, o programa verifica se o peso está dentro do limite definido. Caso exista excesso, calcula o valor da multa com base no peso excedente.

## ⚙️ Funcionamento

O programa considera:

| Tipo de água          | Limite |
| --------------------- | -----: |
| 🌊 Águas continentais |  10 kg |
| 🌊 Águas marinhas     |  15 kg |

Caso o limite seja ultrapassado, é calculada uma multa composta por:

* Multa base: **R$ 1.000,00**
* Valor adicional: **R$ 20,00 por kg excedente**

### 💻 Exemplo

```text
--- Pesca Amadora ---

Peso (em kg)...: 18
Águas [c]ontinentais ou [m]arinhas? M

Pescaria excede os limites legais em 3kg.
Sujeito a multa de R$ 1.060,00.
```
